Instalación sin rodeos

Si ya tienes Claude Code y Node.js 20+, estás a pocos comandos de empezar.

Requisitos previos

Node.js 20+ Preferiblemente LTS.
Claude Code Instalado en tu terminal.
FFmpeg Opcional para edición de vídeo existente.
Whisper.cpp Opcional para subtítulos automáticos.

Verificación rápida

Tras lanzar el entorno de desarrollo, abre http://localhost:3000. Si ves Remotion Studio, ya tienes el taller abierto y listo para fabricar vídeos.

Si FFmpeg o Whisper.cpp fallan, no pasa nada. Son extras para funciones avanzadas. El núcleo de creación de vídeo sigue funcionando.
1) Clonar el repositorio 
git clone https://github.com/Hainrixz/editor-pro-max.git
2) Instalar dependencias 
cd editor-pro-max && npm install
3) Abrir Claude Code 
claude
4) Lanzar la preview 
npm run dev

Prompts para empezar sin pensar demasiado

Pega, ajusta los corchetes y deja que Claude haga lo suyo.

TikTok desde cero

Crea un TikTok de 30 segundos para promocionar [mi producto/servicio].
Estilo: moderno y dinámico.
Incluye texto animado con el nombre del producto, 3 beneficios principales con iconos,
y un call-to-action final.
Usa colores [especifica colores de tu marca].
Formato 9:16 para TikTok.

Subtítulos automáticos

Tengo un video en [ruta/al/video.mp4].
Necesito agregarle subtítulos automáticos.
Usa el preset "bold" para que los subtítulos se vean grandes y con contraste.
Transcribe el audio con Whisper y sincroniza los subtítulos con el habla.

Presentación profesional

Crea una presentación de 2 minutos sobre [tema].
Formato 16:9 para YouTube.
Estructura: intro con título animado, 5 slides con puntos clave,
cada slide con transición suave, y un cierre con logo y contacto.
Estilo: minimalista, fondo oscuro, texto blanco con acentos en [color de marca].

Limpiar un vídeo

Tengo un video largo en [ruta/al/video.mp4]. Necesito:
1) Detectar y eliminar todos los silencios mayores a 0.5 segundos.
2) Aplicar jump cuts automáticos para que quede solo el habla.
3) Exportar el resultado como MP4 para YouTube (16:9).
Consejo práctico: empieza simple, mira el preview y luego afina. Es bastante más rentable iterar 3 veces con intención que escribir un prompt kilométrico y rezar.
